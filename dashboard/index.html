    How the value is worked out

    Implied value = TVL × the median market-cap / TVL ratio of token-bearing peers in the same category (the global median when a category has fewer than 3 peers), times bounded adjustments for 7-day growth, growth against the category median, token-less tenure, TVL scale and chain breadth. The adjustments multiply to between 0.70 and 1.40, and no value passes $10B — or twice the largest peer market cap in its category, where the category has 3 or more peers. Nothing is hardcoded: the whole board is derived from the snapshot at run time, so the same program ranks a future snapshot's protocols.

    Readiness (0–100) is a second dimension, not a second value: tenure 30%, momentum 25%, scale 20%, chain breadth 15%, benchmark strength 10%. It answers how farmable a protocol looks right now; the board still sorts by implied value.
