How the implied value is worked out

1. Peer benchmark, not TVL. For each protocol we take the token-bearing protocols in its own category, compute each peer’s market-cap / TVL ratio, and use the median ratio — the median is robust to the one protocol whose token trades at 400× its TVL. A category with fewer than 3 token-bearing peers falls back to the global median ratio across all token-bearing protocols. Base value = TVL × category median ratio.

2. Bounded adjustments, shown per protocol. Growth: the 7-day TVL change, clamped to ±50%, moves value ±20%. Maturity: listed under a year ago earns +8%, 1–2 years +4%, over 4 years with no token −8%. Scale: over $1B TVL −10%, under $25M +8%. Chains: 2–3 chains +4%, 4 or more +8%. The four multiply together, clamped to 0.70–1.35.

3. A cap. No implied value exceeds $10B, or twice the largest peer market cap in its category — whichever is smaller. Values are rounded to the nearest $10,000.

What this is not. The snapshot records no token; that is not proof a token exists or will ever launch, and the implied value is this radar’s own estimate, never a promise. “Records no token” means DefiLlama carries neither a CoinGecko id nor a symbol for the protocol. Wrapped, staked and bridged products of tokens that already trade are excluded, as are versioned re-releases. All data comes from the sealed snapshot — this page makes no network requests.
